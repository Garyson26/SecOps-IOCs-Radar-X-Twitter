# Contributing to IOC Radar X

First off, thank you for considering contributing to IOC Radar X! It's people like you that make the open-source community such an amazing place to learn, inspire, and create.

## 🤝 How You Can Help

There are many ways to contribute:

1. **Reporting Bugs:** If you find a bug, please open an issue describing the problem, how to reproduce it, and your environment setup.
2. **Suggesting Enhancements:** Have an idea for a new feature? We'd love to hear it! Open an issue outlining your proposal.
3. **Submitting Pull Requests:** If you're ready to write some code, we welcome pull requests!

## 🛠️ Pull Request Process

1. Fork the repository.
2. Create your feature branch: `git checkout -b feature/AmazingFeature`
3. Commit your changes: `git commit -m 'Add some AmazingFeature'`
4. Push to the branch: `git push origin feature/AmazingFeature`
5. Open a Pull Request.

Please ensure your code follows standard Python PEP-8 conventions and doesn't break existing extractor regex patterns. If modifying the `engine/extractor.py`, make sure to validate against false-positive datasets!
